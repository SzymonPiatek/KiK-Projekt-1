## Kryptosystem - szyfr podstawieniowy

Program konsolowy w Pythonie do szyfrowania i deszyfrowania tekstu szyfrem
podstawieniowym.

### Klucz

Klucz podaje użytkownik. Może być:

- **a) liczbą całkowitą** - alfabet szyfrowy jest przesunięty cyklicznie o tę liczbę,
- **b) słowem kluczowym** - min. 8 liter, tworzy własny alfabet szyfrowy.

### Uruchomienie

Wymagany Python 3.10 lub nowszy.

```bash
python main.py
```
